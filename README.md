# LocalChatExport — Vencord

Локальный экспорт загруженной части открытого чата Discord в JSON через команду `/export`.

**Как это работает:** открой чат → введи `/export` → выбери место сохранения → получи уведомление с полным путём к файлу.

Работает в настольном Vencord с native helpers. Это пользовательский плагин для сборки из исходников, не `.plugin.js` для BetterDiscord и не расширение браузера.

## Установка на Windows

Нужны Git, Node.js 22 или новее и pnpm версии, указанной в `package.json` Vencord. Подготовка окружения описана в [официальной инструкции Vencord](https://docs.vencord.dev/installing/).

### Если Vencord уже собирается из исходников

Открой PowerShell. В первой строке укажи путь к **своему** репозиторию Vencord:

```powershell
$vencordPath = 'C:\path\to\Vencord'
$pluginPath = Join-Path $env:USERPROFILE 'vencord-local-chat-export'

git clone https://github.com/rvelabs/vencord-local-chat-export.git $pluginPath
New-Item -ItemType Directory -Force -Path (Join-Path $vencordPath 'src\userplugins') | Out-Null
Copy-Item -LiteralPath (Join-Path $pluginPath 'chatExport.desktop') -Destination (Join-Path $vencordPath 'src\userplugins') -Recurse

Set-Location $vencordPath
pnpm install --frozen-lockfile
pnpm build --dev
```

Если Discord уже использует эту сборку, повторно устанавливать её не нужно. Полностью закрой Discord через значок в трее и запусти заново. Затем открой **Настройки → Vencord → Plugins**, найди **LocalChatExport** и включи его.

Если сборка ещё не установлена в Discord, выполни `pnpm inject` из корня Vencord, выбери нужную установку Discord в установщике, затем запусти Discord и включи плагин.

### Если установлен только обычный Vencord

Копирования файлов в `%APPDATA%\Vencord` недостаточно. Нужно собрать Vencord из исходников по [официальной инструкции](https://docs.vencord.dev/installing/), затем добавить плагин по шагам выше. Подробности: [установка пользовательских плагинов](https://docs.vencord.dev/installing/custom-plugins/).

Итоговая структура должна быть такой:

```text
Vencord/
└── src/
    └── userplugins/
        └── chatExport.desktop/
            ├── index.ts
            ├── native.ts
            └── README.md
```

## Использование

1. Открой личную переписку или канал и дождись загрузки сообщений.
2. Введи `/export`, выбери команду **LocalChatExport** в подсказках и нажми Enter.
3. В диалоге сохранения выбери папку и имя JSON-файла. По умолчанию предлагается папка «Загрузки».
4. После записи появятся число экспортированных сообщений и полный путь к файлу.

Диалог можно отменить: файл не будет создан, плагин покажет отмену. Команда и её служебные уведомления работают локально, сообщения собеседнику не отправляются.

## Формат и ограничения

JSON содержит ID чата, дату экспорта, число сообщений, ID и имена авторов, текст, время отправки и редактирования, тип сообщения, ID ответа и сведения о вложениях.

- **Это снимок текущего кэша, а не полная история чата.** Плагин не подгружает старую историю. Даже прокрутка всей переписки не гарантирует полный экспорт: Discord может выгружать сообщения из кэша. В файле всегда указано `fullHistory: false`.
- Вложения представлены ссылками и метаданными; сами файлы не скачиваются. Ссылки могут истечь.
- Удалённые, временные, неотправленные сообщения и локальные уведомления исключаются.
- Лимит одного экспорта — 32 МиБ.
- Плагин не читает токены, не принимает ID собеседника, не выполняет фоновый экспорт и не отправляет файлы во внешние сервисы.

## Обновление

В папке этого репозитория выполни `git pull`. Скопируй обновлённые файлы в `src/userplugins/chatExport.desktop` своей копии Vencord с заменой, выполни `pnpm build --dev` и полностью перезапусти Discord. Полный перезапуск нужен и после изменений `native.ts`.

## Удаление

Выключи **LocalChatExport** в настройках Vencord. Для удаления исходников убери папку `src/userplugins/chatExport.desktop`, пересобери Vencord и полностью перезапусти Discord.

## Если что-то не работает

- **Команды нет:** проверь, что включён LocalChatExport, папка скопирована без дополнительного уровня вложенности и после сборки Discord полностью перезапущен. Выбирай именно команду этого плагина в подсказках.
- **Нет сообщений для экспорта:** открой нужный чат и дождись загрузки сообщений.
- **Файл не сохранился:** выбери доступную для записи папку и проверь свободное место; подробности ошибки доступны в консоли Vencord.
- **Native helper недоступен:** проверь, что используешь настольный клиент с собственной сборкой, и полностью перезапусти Discord.
