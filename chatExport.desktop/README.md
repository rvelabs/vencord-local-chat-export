# LocalChatExport для Vencord Desktop

Команда `/export` сохраняет JSON со снимком сообщений, уже загруженных в открытом чате. Открывается обычное окно «Сохранить как», после успешной записи плагин показывает полный путь. Отмена диалога не создаёт файл.

## Установка

Нужна собственная сборка Vencord: [официальная инструкция](https://docs.vencord.dev/installing/custom-plugins/). Это исходный userplugin, а не устанавливаемый через интерфейс `.plugin.js`.

1. Скопируй папку `chatExport.desktop` целиком в `src/userplugins/` своего репозитория Vencord.
2. В корне репозитория выполни `pnpm install --frozen-lockfile`, затем `pnpm build --dev`.
3. Установи свою сборку по инструкции Vencord (`pnpm inject`, если она ещё не установлена).
4. Полностью закрой Discord, включая значок в трее, и запусти снова.
5. В настройках Vencord → Plugins включи `LocalChatExport`.

## Использование

Открой нужную переписку или канал. Введи `/export`, выбери локальную команду LocalChatExport в подсказках и нажми Enter. Выбери папку и имя файла в диалоге. Изначально предлагается папка «Загрузки»; итоговый путь зависит от твоего выбора.

Уведомления о подготовке, отмене и результате отображаются в твоём клиенте. Команда не отправляет сообщение собеседнику.

## Что попадает в файл

ID чата, время экспорта, число сообщений, авторы, текст, время сообщения и изменения, ID ответа, сведения о вложениях и их ссылки. Сами вложения не скачиваются; ссылки могут со временем перестать работать.

Это **не полная история**: плагин сохраняет только текущий кэш открытого чата. Прокрутка может менять содержимое кэша, поэтому даже после прокрутки всей беседы файл может содержать лишь её часть. Поле `fullHistory: false` явно отмечает это в JSON. Удалённые, временные, ещё не отправленные сообщения и локальные уведомления исключаются.

Плагин не обращается к API за старой историей, не принимает ID другого пользователя и не отправляет файлы во внешние сервисы. Работает в настольной сборке Vencord с поддержкой native helpers. Лимит одного файла — 32 МиБ.

После изменения `native.ts` требуется полный перезапуск Discord. При ошибке сохранения плагин показывает уведомление; технические подробности доступны в консоли.
